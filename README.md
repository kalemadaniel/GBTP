# GBTP
  >*Le budget de votre projet échappe-t-il à tout contrôle ? Vous ne respectez pas toujours les délais ? Vous faites trop de travail par rapport à ce qui est demandé ? Une mauvaise gestion de projet peut entraîner une baisse du moral des employés, un épuisement professionnel, des dépassements de coûts, des retards, etc. Donnez à votre projet (et à votre entreprise !) les meilleures chances de réussite en utilisant le bon outil de gestion de projet. Ce logiciel gratuit est un début peut vous aider à centraliser la collaboration au sein de l'équipe, à gérer les projets et la charge de travail, et à rationaliser l'ensemble de votre flux de travail BTP!.* 

## Pour commencer

Il prend en paramètre les informations qui nous permet de faire une sauvegarde directement d’une interface java et la faire pour de la partie mysql (Base des données) :

### Pré-requis

Les applications nécessaires pour contribuer au dévéloppement de ce projet :

- Windev <27, 28 et 29 soit la version 2024> (https://pcsoft.fr/st/telec/windev2024/windev2024_45s.htm)
- Téléchargez le package de mise à jour depuis l’URL suivante : (https://package.windev.com/pack/addons/WDMAJCLE/WDMAJCLE.exe)

### Installation

Les étapes pour installer le programme sont :
1. **Télécharger le dossier**
2. **Importer le projet**
3. **Recompiler le projet selon votre version de Windev**
4. **Executer le projet**

ET si vous souhaitez constituer un executable par la suite il faut le faire  et ``Mettre le rendu dans Release``

## Mode ligne de commande
